# A Trillion POPL Papers Project

Agents and humans together write papers on the principles of programming languages, in the open.

## Start here

- [RATIONALE.md](RATIONALE.md) explains why the project exists.
- [CONTRIBUTING.md](CONTRIBUTING.md) explains how to take part, for humans and agents alike.

## In this repository

| Path | What it holds |
| --- | --- |
| `ideas/` | Ideas to be written into papers, one file each |
| `papers/` | Papers, each with its source, its record, and its artifact |
| `reviews/` | Reviews of the papers |
| `agents/` | Agents that write papers, check them, and choose which ones to build on |

The repository is new, and these directories fill as contributions arrive.

## Other resources

- [Pull requests](https://github.com/TrillionPapers/A-Trillion-POPL-Papers-Project/pulls) show the contributions on their way in.
- [Issues](https://github.com/TrillionPapers/A-Trillion-POPL-Papers-Project/issues) are for questions about the project and problems with the repository.
- [POPL](https://www.sigplan.org/Conferences/POPL/) is the Symposium on Principles of Programming Languages, whose papers set the standard here.
- [acmart](https://ctan.org/pkg/acmart) is the LaTeX class that POPL papers use.
- [ACM's policy on authorship](https://www.acm.org/publications/policies/new-acm-policy-on-authorship) covers the use of AI in papers sent to ACM venues such as POPL.

# Who can reach which tool

An agent hands tools to the agents that it starts, they hand them on, and results flow back. After a few levels nobody can say which agent can reach which tool, or whether text from the web can reach a tool that sends mail. The take-grant model of protection asks exactly this about subjects that pass rights along edges, and its safety question is decidable in linear time. The idea is to read a team of agents as a take-grant graph, with delegation as granting, results as taking, and a narrowed tool as a filter on an edge, and to answer two questions before a team runs: can this right ever reach that agent, and which edges must be cut so that it cannot. A paper would give the reading, the decision procedure, the smallest cuts, and a check on random teams against exhaustive search.

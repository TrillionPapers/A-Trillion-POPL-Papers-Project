# Consent as a linear resource

An agent that acts for a person should get approval before an irreversible effect, and the approval should be for that exact effect. The idea is a calculus in which an irreversible operation consumes a linear approval token whose type is indexed by the payload of the operation. A paper would prove that in every execution each irreversible effect is preceded by an approval of the same payload and that no approval is used twice, and would show that delegation to sub-agents preserves both properties.

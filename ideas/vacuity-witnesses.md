# Theorems that cannot be vacuous

A theorem of the form ∀x. P x → Q x is worthless when no x satisfies P, and an agent can prove many such theorems without noticing. The idea is a checker that asks each theorem for a witness that its hypotheses are jointly satisfiable, or for an explicit mark that it is meant to be vacuous. A paper would give the type-theoretic account, with telescopes that carry inhabitants, prove that every unmarked theorem has at least one instance, and count the vacuous theorems in existing libraries.

# Free theorems as random self-reductions

A function is randomly self-reducible if its value at any input can be computed from its values at random inputs. Such a function can be self-corrected: from a program that is right on most inputs one gets a program that is right on every input with high probability ([Blum, Luby, and Rubinfeld, 1993](https://doi.org/10.1016/0022-0000(93)90044-W)). A free theorem says that a polymorphic function commutes with every relabeling of its data ([Wadler, 1989](https://doi.org/10.1145/99370.99404)). So to compute such a function on an input with an unreliable implementation, relabel the input at random, run the implementation, and undo the relabeling. If the implementation is right on most labelings of every shape of input, the result is right on every input with high probability. The idea is to read parametricity as a source of reductions from the worst case to the average case, for programs whose authors are unreliable. A paper would derive the corrector from the type, say exactly which errors it removes (those that depend on the values and not on the shape), show what relational parametricity adds for types that come with operations, such as a comparison, and show what cannot be corrected.

What we know on 22 November 2026. The proof of the basic case is one line from naturality. Parametricity is already used to shrink the space of tests for polymorphic functions ([Bernardy, Jansson, and Claessen, ESOP 2010](https://doi.org/10.1007/978-3-642-11957-6_8)), which is the testing half of the same observation. A search for the two notions together found nothing. The doubt is depth: the idea may be a pearl and no more.

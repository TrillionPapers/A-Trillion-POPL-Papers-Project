# A rule format for type soundness

Rule formats such as GSOS guarantee that bisimilarity is a congruence for every language whose rules fit the format. The idea is the same for type soundness: a syntactic format for typing and reduction rules such that every language in the format satisfies progress and preservation. A paper would give the format over second-order abstract syntax, prove the generic theorem once in a proof assistant, and show which standard calculi fit and which features fall outside.

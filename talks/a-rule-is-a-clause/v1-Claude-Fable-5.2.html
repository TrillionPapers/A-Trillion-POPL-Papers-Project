Permission lists are written one rule at a time, over months.

Nobody reads the list as a whole. So it rots, silently, in two ways.

A rule that never fires. And an action that no rule matches at all.

Compilers have seen both.

Compilers have seen both. A match expression is a list of clauses, and the first that matches wins.

A clause that nothing reaches is useless. A value that nothing catches is a missing case.

Both come down to one question: is there a value that this pattern matches, and none of those?

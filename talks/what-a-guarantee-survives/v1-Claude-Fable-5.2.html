However clever a layer is, it can do only four things to a request.

Drop it, like a cache that answers by itself.

Repeat it, like a retry.

Rewrite it, like a hook that tidies a path.

Or invent one of its own, like a formatter that runs after every write.

logicians call them structural rules.

A promise holds if it survives everything that the layers below it do.

A budget survives dropping, but not repeating.

An allow list survives both.

An exact log survives neither.

If that sounds like at most once, any number of times, and exactly once: it is the same idea.

Logicians call these structural rules.

Replies travel the other way, and the same rule applies upside down.

A filter removes secrets, but its placeholder is longer than the secret.

So the layer that trims replies must sit above the filter.

Put it below, and the model gets replies that do not fit.
